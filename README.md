# Рунет Заметки

Небольшой информационный блог о компаниях российского интернета: главная и две статьи (Авито и 2ГИС).

Сайт статический: чистые HTML и CSS, без сборки, скриптов и зависимостей. Подходит для GitHub Pages и для обычного хостинга.

## Что внутри

```
index.html         главная с карточками двух статей
posts/avito.html   статья про Авито
posts/2gis.html    статья про 2ГИС
assets/style.css   оформление (светлая и тёмная тема подстраиваются под систему)
assets/favicon.svg значок сайта
```

Все ссылки относительные, поэтому сайт работает и по адресу `логин.github.io/runet-blog/`, и в корне собственного домена.

## Посмотреть у себя

Откройте `index.html` двойным кликом.

## Загрузить на InfinityFree

1. Распакуйте архив `runet-blog-infinityfree.zip` на компьютере.
2. В панели InfinityFree откройте **Online File Manager** (или подключитесь по FTP, например через FileZilla) и зайдите в папку `htdocs`.
3. Загрузите в `htdocs` **содержимое** распакованной папки: `index.html`, `posts` и `assets`. Сам zip загружать не нужно: файловый менеджер InfinityFree не умеет надёжно его распаковывать.
4. Откройте адрес сайта и проверьте главную и обе статьи.

## Перед запуском рекламы в Яндекс Директе

В справке Директа сказано, что на сайте нужно указать контакты организации или предпринимателя (юридическое наименование, фактический адрес, телефон, ОГРН или ИНН). Эти данные сюда не вписаны, потому что их знаете только вы. Добавьте блок в подвал `index.html` и обеих статей, перед строкой с копирайтом:

```html
<p>ИП Фамилия Имя Отчество, ИНН 000000000000. Адрес: … Телефон: … Почта: …</p>
```

Также до запуска проверьте, что сайт открывается для робота Яндекса без проверки браузера: инструмент «Проверка ответа сервера» в Яндекс Вебмастере покажет, что именно получает робот.

## О фактах

Тексты основаны на открытых источниках и могут устаревать. Перед публикацией новых цифр сверяйте их с официальными сайтами компаний.
