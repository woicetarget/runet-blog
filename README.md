# Рунет Заметки

Небольшой блог о компаниях российского интернета: Яндекс, VK, Ozon, Wildberries, Авито, Т-Банк, 2ГИС и hh.ru. Плюс хронология Рунета с 1994 по 2024 год.

Сайт статический: чистые HTML, CSS и немного JavaScript, без сборки и зависимостей. Подходит для GitHub Pages как есть.

## Что внутри

```
index.html         главная: карточки статей, фильтр по направлениям, поиск
timeline.html      хронология Рунета
posts/*.html       восемь статей
assets/style.css   оформление (светлая и тёмная тема подстраиваются под систему)
assets/script.js   фильтр и поиск на главной
assets/favicon.svg значок сайта
```

Все ссылки относительные, поэтому сайт работает и по адресу `логин.github.io/runet-blog/`, и с собственным доменом.

## Посмотреть у себя

Откройте `index.html` двойным кликом, отдельный сервер не нужен.

## Выложить на GitHub Pages

Через терминал (нужен установленный и авторизованный `gh`):

```bash
cd ~/Downloads/ClaudeFile/runet-blog
git init -b main
git add .
git commit -m "Блог про компании Рунета"
gh repo create runet-blog --public --source=. --push
```

Затем на GitHub: репозиторий → **Settings** → **Pages** → **Build and deployment** → Source: **Deploy from a branch** → ветка `main`, папка `/ (root)` → **Save**.

Через минуту-две сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/runet-blog/`.

## Как добавить статью

1. Скопируйте любой файл из `posts/`, например `posts/ozon.html`, под новым именем.
2. Поменяйте заголовок, текст, блок «Основан / Сервисы» и список «Что запомнить».
3. На главной в `index.html` скопируйте один блок `<li data-cat="…">…</li>` внутри `<ul class="grid">`: поменяйте ссылку, название, описание и `data-text` (слова, по которым работает поиск).
4. Направление в `data-cat` берите из кнопок фильтра: `search`, `social`, `market`, `fintech`, `career`. Цвет значка задаётся числом в `style="--h:…"` (от 0 до 360).
5. Для хронологии добавьте строку в `timeline.html` по образцу соседних.

## О фактах
